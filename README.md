# Fashion-MNIST Image Classification Using Simple RNN

## 📌 Project Overview
This project implements a Simple Recurrent Neural Network (RNN) to classify clothing images from the Fashion-MNIST dataset into 10 different categories.

## 🎯 Objectives
- Understand how Simple RNN works for image classification.
- Preprocess and normalize image data.
- Train and evaluate a deep learning model.
- Visualize training accuracy and loss.
- Generate predictions and a confusion matrix.

## 📊 Dataset
The Fashion-MNIST dataset contains 70,000 grayscale images of clothing items:
- 60,000 training images
- 10,000 test images
- Image size: 28 × 28 pixels
- Number of classes: 10

## 🛠️ Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## 🧠 Model Architecture
The model uses SimpleRNN layers, dropout layers, and dense layers to classify images into 10 categories.

## 📈 Evaluation
The project evaluates the model using:
- Accuracy
- Loss
- Confusion Matrix
- Classification Report
- Actual vs. Predicted Images

*Add the actual test accuracy and loss after running the notebook.*

## 🚀 How to Run
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. The Fashion-MNIST dataset will be loaded automatically through TensorFlow/Keras.
4. Train the model and review the evaluation results.
